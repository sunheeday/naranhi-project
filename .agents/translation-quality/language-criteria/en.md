# English (en) — Evaluation & Translation Criteria

## Migrant Parent Profile (north star 페르소나)

평가·번역의 절대 기준은 **이 페르소나가 정확하게 이해할 수 있는가**다.

- 영어가 모국어이거나 가족 내 주 사용 언어인 한국 거주 이주민 학부모
- 출신 다양: 미국·영국·캐나다·호주 등 영어권 + 필리핀·인도·나이지리아·말레이시아 등 영어를 모국어/공용어로 사용하는 다국적 가정
- 교육 수준 다양 — 고학력일 수도, 일반 노동 가정일 수도
- 한국 학교 문화 친숙도 낮음 (학예회·알림장·체험학습·돌봄교실 사전 지식 없음)
- 한국 거주 기간 다양 (신규 ~ 장기)

### 이 페르소나의 평가 기준

- **Standard plain English**가 정답. legalese (`hereby notify`, `the undersigned`), 마케팅 톤, 슬랭, 지나치게 학술적인 어휘는 감점.
- 미국식/영국식은 한 문서 내 일관성만 지키면 OK. 본 프로젝트는 **American English 기본** 권장.
- 한국 학교 특유 개념은 풀어쓰기 + 원어 병기 권장 (예: `학예회 (school talent show day)` — 단 fact 추가 금지 원칙에 위배되지 않는 범위에서, 사전 매핑이 있을 때만).
- 평균 8~10학년(영미 중학생) 가독 수준이 목표. Flesch Reading Ease ~60 근처.

### 자주 깨지는 north star 신호

- "Please be advised that the aforementioned event ..." 같은 법무체 → 이해 장벽
- `subject to ... pursuant to ...` 등 행정 영문 jargon → 감점
- 학교 개념 그대로 음역 (`Hakyehoe will be held ...`) → 의미 전달 실패
- 마감/시간을 한국식으로 그대로 (`PM 2시`, `AM 9시`) → 자연스럽지 않음 + 신규 이주민이 잠시 헷갈림

## 평가 시 반드시 점검할 항목 (체크리스트)

### Register / Formality
- [ ] 학교 공식 통신문 격식 (어드미니스트레이티브 영어 — "We kindly inform parents that ..." 톤)
- [ ] 명령형 남용 없음 — `Submit by Monday` 대신 `Please submit by Monday`가 기본. 다만 안전 경고는 직접적인 명령형이 적절할 수 있음
- [ ] 한국식 직역 흔적 없음 — `please understand` (양해 부탁드립니다 → "we appreciate your understanding"), `give a lot of love` (많이 사랑해 주세요 → 영어 통신문에서는 거의 쓰지 않음, 삭제 또는 재구성)
- [ ] 비즈니스 영어 톤이 아니라 공교육 톤 — `We hereby notify` 등 법무체는 과도

### Lexical / Idiomatic
- [ ] 학교 용어가 K-12 미국식/영국식 기준으로 자연스러운가:
  - 학년 표기: `1st grade` (미국식) 또는 `Year 1` (영국식) — 한 통신문 안에서 혼용 금지
  - 학부모: `parent/guardian` (단순 `parents`는 한부모/조부모 양육 가정 배려가 약함)
  - 가정통신문: `school newsletter` / `family letter` / `notice`
  - 알림장: `home-school communication`, `daily log`
  - 급식: `school lunch` (미국식) / `school meal` (영국식)
  - 방학: `school holidays` / `vacation`
- [ ] 한자어 직역 금지 — `participate` 대신 `take part`가 더 자연스러운 경우가 많음

### Numbers, Dates, Times
- [ ] 날짜: 단일 형식 유지. 권장 `June 1, 2026 (Mon)` 또는 `1 June 2026 (Mon)`. 요일을 포함하면 보호자가 일정 잡기 쉬움
- [ ] 시간: 12시간제 `2:30 PM` 또는 24시간제 `14:30`. 한 문서 안에서 혼용 금지
- [ ] 한국 원화: `KRW 30,000` 또는 `30,000 won` — 통일
- [ ] 전화번호: 한국 형식 그대로 (`02-1234-5678`, `010-1234-5678`). 국제전화 형식 변환 금지(원문에 없으면)
- [ ] 학년-반: `Grade 1, Class 3` 또는 `1-3` 둘 중 일관 — 단 첫 등장 시 풀어 쓰기 권장

### Punctuation / Typography
- [ ] 영어 따옴표/괄호 사용 ("", '', () — 한국식 「」, 『』 잔존 금지)
- [ ] 한국식 중점·물결(·, ~) 잔존 금지 — 영어 통신문은 콜론/대시 사용
- [ ] 줄바꿈으로만 구분된 한국어식 목록은 영어 bullet 또는 번호 목록으로 변환

### Action Clarity
- [ ] "What / When / How" 3요소가 한 단락 안에 들어 있는가
- [ ] 회신/제출 방법이 분명한가 (`Please return the signed form to your child's homeroom teacher by ...`)
- [ ] 마감일에 요일 동반 권장

### Cultural Mapping
- [ ] 한국 특유의 학교 행사명을 보충 — `학예회` → `school performance day (학예회)` 처럼 한국어 병기를 권장하는 경우가 있음. 단 hard fact 보존 우선.
- [ ] 종교적·문화적 함의 — 영어권에서는 비교적 중립이지만 부활절/크리스마스 휴일 언급 시 한국 학교 일정과 다를 수 있음을 임의로 보충하지 말 것

### Meal / Allergy 표기
- [ ] 알레르겐 표시 관행: `Contains: milk, egg, wheat, soy` 라인을 별도로
- [ ] 미국식 알레르겐 9종(milk, egg, fish, shellfish, tree nuts, peanuts, wheat, soybeans, sesame)과 한국식 알레르겐 표기가 다를 수 있음 — 임의 통합 금지, 사전 매핑 기반만

### Naturalness 직역 안티 패턴 (자주 발견되는 것들)
- 한국식 시간 표현: `오전 9시부터 오후 1시까지` → ❌ `from AM 9 to PM 1`, ✅ `from 9 AM to 1 PM`
- 호칭: `학부모님께` → ❌ `To honorable parents`, ✅ `Dear parents and guardians,`
- 인사: `안녕하십니까` → ❌ `Are you peaceful?`, ✅ 첫 문장은 종종 생략하고 바로 본론
- 마감 강조: `반드시 ... 해 주시기 바랍니다` → ❌ `must please`, ✅ `Please be sure to ...`
- 학년 반: `5학년 3반` → 일관되게 `Grade 5, Class 3` 또는 `5-3`

## 엔지니어가 영어 프롬프트 설계 시 다뤄야 할 항목

`translate_en_to_target_prompt` 또는 (분리 시) `prompts_en.py`의 영어 전용 프롬프트에 다음 룰을 명시한다.

1. **Register lock**: "Use the register of US public-school administrative communication: polite, neutral, action-oriented. Avoid legalese, marketing tone, and casual chat."
2. **Action template**: "For every required action, surface WHAT / WHEN (with weekday) / HOW (channel) in a single paragraph or bullet."
3. **Date/time consistency**: 한 문서 안에서 시간·날짜 표기 형식을 통일하도록 명시.
4. **Direct translation guardrails**: 위 안티 패턴 5–6개를 예시로 박아 넣기 ("Do NOT output: 'Are you peaceful?' / 'AM 9' / ...").
5. **Length tolerance**: 영어가 한국어보다 1.2–1.5배 길어질 수 있음을 허용하되, 부수 설명 추가는 금지.
6. **Greeting handling**: 한국 통신문의 의례적 인사("안녕하십니까")는 영어에서 한 줄 인사 또는 생략 가능. 본문 사실은 절대 손대지 않음.
7. **British vs American**: 기관 정책 합의 — 본 프로젝트는 **American English** 사용 (필요 시 조정 가능). 첫 단계 sysprompt에 명시.
8. **Allergen vocabulary**: 사전 매핑만 사용한다는 룰을 영어에도 동일하게 강조. `Contains:` 형식 권장.

## 자주 보는 문제와 어디서 잡을 수 있는가

| 문제 | 발생 가능 단계 | 잡는 곳 |
|---|---|---|
| `AM 9` 같은 직역 | `translate_en_to_target_prompt` 또는 `translate_ko_to_en_pivot_prompt` | 영어 프롬프트에 안티 패턴 예시 |
| 마감일 요일 누락 | hard_fact 추출 시 요일 포함 안 됨 | `extract_source_hard_facts_prompt`에서 dates 추출 시 weekday 같이 normalize |
| 명령형 남용 | 영어 프롬프트의 register 룰 약함 | "polite request" 룰 명시 |
| 학년-반 표기 혼용 | 단일 형식 강제 룰 없음 | 영어 프롬프트에 표기 형식 고정 |
