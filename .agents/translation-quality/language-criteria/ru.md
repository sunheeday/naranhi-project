# Russian (ru) — Evaluation & Translation Criteria

## Migrant Parent Profile (north star 페르소나)

평가·번역의 절대 기준은 **이 페르소나가 정확하게 이해할 수 있는가**다.

- 러시아어가 모국어 또는 가족 내 공용어인 한국 거주 이주민 학부모
- **주 출신: 중앙아시아 (우즈베키스탄·카자흐스탄·키르기스스탄·타지키스탄)**, 그다음 러시아·우크라이나·고려인(CIS) 가정
- 일부 보호자에게 러시아어는 모국어가 아니라 제2언어(중앙아시아 출신 다수). 따라서 **표준·단순 러시아어**가 정답이지 문학적·고급 어휘는 장벽
- 교육 수준 다양 — 일반 노동 가정 비중 높음
- 한국 학교 문화 친숙도 낮음 (학예회·알림장·돌봄교실 사전 지식 없음)
- 무슬림 가정 비율 높음 → 식이·종교 민감도 높음

### 이 페르소나의 평가 기준

- **소비에트식 표준 행정 등록(стандартный административный регистр)**이 정답. 한국 학교가 행정 통지를 보내는 톤과 가장 가깝고, 중앙아시아 출신에게도 익숙.
- 문학적 어휘·고전 인용·시적 표현 회피.
- 어휘 난도: 일상 행정·교육 어휘 위주. 추상 명사 남발 금지.
- 정중 호명 `Уважаемые родители!`로 시작, 본문은 `Вы` (대문자) 일관.
- 한국 학교 특유 개념은 풀어쓰기 + 원어 병기 권장 (예: `Хакёхве (школьный праздник)`) — 단 fact 추가 금지에 위배되지 않는 범위.

### 자주 깨지는 north star 신호

- 문학적·시적 어휘 사용 → 신규 중앙아시아 이주민이 못 읽음
- `соблаговолите`, `извольте` 같은 고전·관료적 어휘 → 거리감 + 이해 장벽
- 학교 개념 단순 음역 (`Хакёхве будет проводиться ...`) → 의미 전달 실패
- 한국식 시간 표기 그대로 (`AM 9 часов`) → 즉각 혼란
- 격·수 일치 오류(`2 ребёнок`) → 신뢰도·이해도 동시 손상

## 평가 시 반드시 점검할 항목 (체크리스트)

### Register / Formality
- [ ] 공식 학교 통신문 톤 — `Уважаемые родители!` (학부모님께) 같은 정중 호명 사용
- [ ] 동사형: 명령형(повелительное наклонение) 직접 사용 최소화. 정중 요청은 `Просим Вас + 명사/неопр. форма` 또는 `Пожалуйста, ...`
- [ ] 2인칭 `Вы`(존칭 복수)로 일관 — 학교 → 학부모 통신은 항상 대문자 `Вы` (러시아식 정서법)
- [ ] 한국식 직역 흔적 없음 — `пожалуйста поймите` (양해 부탁드립니다 → 자연어는 `Благодарим за понимание`)

### Lexical / 학교 용어
- [ ] 학년: `1-й класс`, `2-й класс` (러시아 학제와 다르더라도 한국 학년에 맞춰 표기). 처음 등장 시 `(класс начальной школы — 초등 X학년)` 같은 보충은 권장되지 않음 (사실 추가 금지 원칙). 단순히 `1-й класс` 유지.
- [ ] 학부모: `родители и опекуны` (단순 `родители`보다 포괄적). 단, 짧은 호명에는 `Уважаемые родители!`로 충분
- [ ] 가정통신문: `информационное письмо для родителей`, `школьное уведомление`
- [ ] 담임: `классный руководитель`
- [ ] 급식: `школьное питание`, `школьный обед`
- [ ] 학예회 등 학교 행사: 한국어 명을 라틴 음역 + 러시아어 설명 보충은 **금지** (사실 추가). 사전 매핑 또는 의미 번역만.

### Numbers, Dates, Times
- [ ] 날짜: 러시아식 `1 июня 2026 г. (понедельник)` 권장 — 월 이름은 소문자
- [ ] 시간: 24시간제 `14:30` 표준. 12시간제(`2:30 PM`) 사용 금지
- [ ] 금액: `30 000 южнокорейских вон (KRW)` — 천 단위 구분은 공백 (러시아식). 통화 명칭은 처음 등장 시 풀어쓰기, 이후 `KRW` 또는 `₩`
- [ ] 전화번호: 한국 형식 그대로 (`02-1234-5678`) — 국제번호 변환 금지(원문에 없으면)
- [ ] 학년-반: `1-й класс, 3-й подкласс` 또는 단순히 `1-3` 일관 사용

### Grammar / 격변화 (러시아어 특수)
- [ ] **격(падеж) 일치** — 한국 학교명·학생 이름이 러시아어 격변화를 따르지 않을 수 있음. 원문 인명/학교명은 주격 그대로 유지하되 문맥상 다른 격이 자연스러우면 따옴표 안에 주격으로 둘 수 있음 (`в школе "나란히"`)
- [ ] **수 일치** — 1, 2-4, 5+ 에 따라 명사 어미가 달라짐 (`1 ребёнок / 2-4 ребёнка / 5+ детей`). 잘못된 형태가 자주 발생
- [ ] **동사 상(вид)** — 완료/불완료 선택. 일회성 행동은 완료상 (`подайте заявление`), 반복은 불완료상
- [ ] **부정 표현** — 부정문에서 직접 목적어는 종종 생격 (`не забудьте принести (что? — генитив 또는 аккузатив)`)
- [ ] 학교명·고유명사 따옴표는 « » 또는 " " 사용. 한국식 「」 금지

### Punctuation / Typography
- [ ] 러시아식 따옴표: 「외부 « », 내부 „ "」 또는 단순 " " 일관
- [ ] 줄임표: `…` (점 세 개)
- [ ] 한국식 중점(·)은 콤마 또는 세미콜론으로 교체

### Action Clarity
- [ ] "Что нужно сделать / К какому сроку / Как" 3요소 명시
- [ ] 회신: `Пожалуйста, верните подписанную форму классному руководителю до ...` 형태로

### Cultural Mapping
- [ ] 중앙아시아 출신 보호자 비율이 높을 수 있어 종교적 함의(돼지고기 등)는 사전 매핑에 따라 명확히
- [ ] 정교회 휴일/세속 휴일을 임의 보충 금지 — 한국 학교 일정만 그대로
- [ ] 호명 — `Уважаемые родители!` 이후 본문은 `Вы`로 통일

### Meal / Allergy 표기
- [ ] 알레르겐: `Содержит: молоко, яйцо, пшеница, соя` 형식
- [ ] 돼지/소/닭/해산물/우유/계란/밀/콩/알코올 유래/젤라틴 → critical 표기 (러시아어권 무슬림 가정 다수 고려)
- [ ] 사전 매핑만 사용. 임의 음역 또는 추측 금지

### Naturalness 직역 안티 패턴
- `안녕하십니까` → ❌ `Здравствуйте, как ваше спокойствие?`, ✅ `Уважаемые родители!` 한 줄로
- `많은 관심 부탁드립니다` → ❌ `Просим много внимания`, ✅ `Благодарим за внимание` 또는 생략
- `오전 9시부터` → ❌ `с AM 9`, ✅ `с 9:00`
- `학부모님의 협조 부탁드립니다` → ❌ `Просим сотрудничества родителей`, ✅ `Благодарим Вас за поддержку`
- `... 해 주시기 바랍니다` 반복 → 한 단락에 한 번만 `Просим Вас + ...` 권장

## 엔지니어가 러시아어 프롬프트 설계 시 다뤄야 할 항목

`prompts_ru.py`(분리 시) 또는 `translate_en_to_target_prompt`에서 `target_language == "ru"`일 때 다음 룰을 명시한다.

1. **Register lock**: "Use formal Russian school administration register. Address parents as `Вы` (capitalized) consistently. Use `Уважаемые родители!` as opening when an opening is appropriate."
2. **Imperative softening**: "Avoid direct imperative for requests to parents. Use `Просим Вас + verb`, `Пожалуйста, ...`, or `Просим обратить внимание`."
3. **Number agreement**: "Apply correct numeral-noun agreement: 1 → nominative singular, 2–4 → genitive singular, 5+ → genitive plural. Examples: `1 ребёнок / 2 ребёнка / 5 детей`."
4. **Verb aspect**: "Use perfective for single bounded action (`подайте`, `принесите`), imperfective for habitual/ongoing actions."
5. **Time/date format**: "Use 24-hour time (`14:30`). Use Russian date format `1 июня 2026 г. (понедельник)` — month name lowercased."
6. **Phone/account preservation**: "Preserve Korean phone numbers and account numbers exactly as in source. Do not convert to international format."
7. **Proper noun handling**: "Korean school names and student names: keep in nominative case, optionally inside `«»`. Do not invent declensions."
8. **No invented context**: "Do not add Russian cultural explanations (Orthodox holidays, regional customs) unless explicitly in source."
9. **Allergen format**: `Содержит: ...` 라인 권장.

## 자주 보는 문제와 어디서 잡을 수 있는가

| 문제 | 발생 가능 단계 | 잡는 곳 |
|---|---|---|
| 수-명사 일치 오류 (`2 ребёнок`) | 러시아어 번역 단계 | 러시아어 전용 프롬프트에 일치 예시 박기 |
| 격 오류 (학교명 인격화) | 러시아어 번역 단계 | "고유명사는 주격 유지" 룰 |
| 12시간제 혼용 | 영어 피벗에서 그대로 넘어옴 | 러시아어 단계에서 24시간제 강제 변환 룰 |
| 강압적 명령형 | 톤 룰 약함 | `Просим Вас` 패턴 강제 |
| `Вы` 소문자 사용 | 정서법 룰 누락 | 러시아어 전용 프롬프트에 명시 |
