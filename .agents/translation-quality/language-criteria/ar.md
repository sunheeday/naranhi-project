# Arabic (ar) — Evaluation & Translation Criteria

## Migrant Parent Profile (north star 페르소나)

평가·번역의 절대 기준은 **이 페르소나가 정확하게 이해할 수 있는가**다.

- 아랍어가 모국어인 한국 거주 이주민 학부모
- 다양한 출신: 이집트·시리아·이라크·예멘·모로코·튀니지·요르단·수단·소말리아 등. **방언은 출신마다 상호 비호환** — 따라서 표준 아랍어(MSA, فصحى) 외 선택지가 없다
- 다수가 무슬림 가정 — 종교·식이 규범(특히 돼지·알코올·젤라틴) 민감도 최상
- 교육 수준 다양 — 신규 이주 가정의 경우 고전 아랍어·종교 문헌 수준의 고급 MSA는 이해 장벽
- 한국 학교 문화 친숙도 낮음
- RTL 사용

### 이 페르소나의 평가 기준

- **"신문/학교 통신문 수준의 접근 가능한 MSA"** — 알자지라/BBC 아랍어 뉴스 등록이 가장 가깝다. 이는 행정 표준이면서도 다양한 출신·교육 수준의 보호자가 이해 가능
- **고전·종교적 어휘 회피** — `حضرات أولياء الأمور الكرام،`은 표준 행정 호명으로 OK, 그러나 `يا أولياء الأمور الأفاضل` 같은 시적·고전 호명은 거리감 + 장벽
- **방언 표현 절대 금지** — 한 명의 학부모는 알아도 다른 출신은 못 알아들음
- **문장 길이 조절** — 고전 아랍어식 긴 복합문 회피. 짧고 명확한 행정 문체
- 종교적 관용어(`إن شاء الله`, `بسم الله`) 자동 삽입 금지 — 이주민 학부모 다수가 종교 정체성을 두고 다양함, 그리고 학교는 세속 행정 주체
- 한국 학교 특유 개념은 의미 번역 + 한국어 원어 병기 권장: `يوم العروض المدرسية (학예회)`

### 자주 깨지는 north star 신호

- 고전적·시적 MSA (코란/고전 시 어휘) → 신규 이주민이 이해 못 함
- 방언 어휘 1~2개 섞임 → 다른 출신 학부모가 멈춤
- 학교 개념 단순 음역 (`الهاكيوهوي سيُعقد ...`) → 의미 전달 실패
- 종교 관용어 자동 삽입 → 비종교/타종교 가정 거리감, 학교가 종교 주체로 오해
- 동·서양 숫자 혼용 → 이해 장벽
- 헤지라력 임의 추가 → 원문 fact 왜곡
- 돼지/알코올/젤라틴 임의 음역 → 안전·종교 critical 실패

## 평가 시 반드시 점검할 항목 (체크리스트)

### Register / Formality
- [ ] **Modern Standard Arabic (MSA, الفصحى)** 사용. 이집트·레반트·걸프 방언 표현 금지
- [ ] 학교 행정 통신 격식 — `حضرات أولياء الأمور الكرام،` (존경하는 학부모님께) 같은 정중 호명
- [ ] 동사형: 명령형 직접 사용 자제. 정중 요청은 `يُرجى + 마스다르(동명사)` 또는 `نرجو من حضراتكم + 마스다르` 구조 권장
- [ ] 너무 종교적·시적 표현 금지 (학교 통신문은 행정 톤. 인사구로 `بسم الله` 등을 임의로 추가 금지)
- [ ] 한국식 직역 흔적 없음

### Script / Direction (가장 중요)
- [ ] **RTL(우→좌) 방향** — 줄바꿈, 단락 정렬, 글머리 기호 위치 모두 RTL 기준
- [ ] 라틴 문자/숫자 혼용 시 BiDi 처리 잘못된 흔적 없음 (예: 전화번호 `02-1234-5678`가 거꾸로 나타나거나, 한국어 학교명이 글자 순서가 뒤집힌 경우)
- [ ] **숫자 표기 정책** — 본 프로젝트는 다음을 권장:
  - **서양식 아라비아 숫자(Western Arabic numerals)** 0–9 사용: `1` `2` `3`
  - 동양식 인도-아라비아 숫자(`٠ ١ ٢ ٣`)는 사용하지 않음 (혼선 방지)
  - 단일 정책으로 일관. 혼용 금지
- [ ] 한국어 고유명사(학교명·인명)는 아랍어 음역 + 괄호 안 원문 한국어 보존 권장: `مدرسة "나란히"` 또는 `مدرسة Naranhi`

### Lexical / 학교 용어
- [ ] 학년: `الصف الأول`, `الصف الثاني` (한국 학년 그대로). 사우디·이집트 학제와 다를 수 있으나 한국 학년 표기를 따른다
- [ ] 학부모/보호자: `أولياء الأمور` (포괄적). 단순 `الآباء`(아버지들)은 사용 자제
- [ ] 가정통신문: `إشعار مدرسي` / `رسالة إلى أولياء الأمور`
- [ ] 담임교사: `معلم الفصل` / `المعلم المسؤول عن الفصل`
- [ ] 급식: `وجبة الغداء المدرسية` / `الوجبة المدرسية`
- [ ] 학예회 등 한국 학교 행사: 사전 매핑 기반 음역 + 의미 번역. 임의 해석 금지

### Numbers, Dates, Times
- [ ] 날짜: 그레고리력 우선 `1 يونيو 2026 (الاثنين)` — 월 이름 아랍어로. 헤지라력(هـ) 병기는 **금지** (원문에 없으므로 사실 추가)
- [ ] 시간: 24시간제 `14:30` 권장. 또는 `الساعة 2:30 مساءً`. 한 문서 안에서 혼용 금지
- [ ] 금액: `30,000 وون كوري جنوبي` 또는 `30,000 KRW` — 첫 등장 시 풀어쓰기. 천 단위 구분자는 `,` 사용 (서양 표기 일치)
- [ ] 전화번호: 한국 형식 그대로, 라틴 숫자
- [ ] 학년-반: `الصف 1، الفصل 3` 또는 `1-3` 일관 사용

### Grammar 특수
- [ ] **타니인(تنوين)·격조사·태마지(تاء مربوطة) 표기** — 정자체 표준 표기 준수
- [ ] **동사 일치** — 성·수 일치 (남성/여성 단·쌍·복수)
- [ ] **연계형(إضافة)** — 단어 결합 시 알(الـ) 사용 규칙 준수
- [ ] **숫자-명사 일치 규칙** — 아랍어는 수에 따라 명사의 성·격이 바뀜 (3–10은 반대 성, 11–99 등 규칙). 직역기 결과에서 자주 깨짐

### Punctuation / Typography
- [ ] 아랍어 콤마 `،` (U+060C), 세미콜론 `؛` (U+061B), 물음표 `؟` (U+061F) 사용
- [ ] 줄임표 `…`
- [ ] 한국식 중점(·)·물결(~)·낫표(「」) 잔존 금지

### Action Clarity
- [ ] "ما المطلوب / متى الموعد النهائي / كيف" 3요소 명시
- [ ] 회신: `يُرجى إعادة النموذج الموقَّع إلى معلم الفصل بحلول ...`

### Cultural & Religious (가장 민감)
- [ ] **돼지/돼지고기 유래 재료** — 가장 엄격. 사전 매핑 외 임의 번역 절대 금지. 미매핑이면 `human_review_required=true`
- [ ] **알코올 유래 재료**(맛술·미림·바닐라 추출물 등) — 동일하게 critical
- [ ] **젤라틴**(소·돼지 출처 모호) — critical
- [ ] **할랄 가정 배려** — 식단에 돼지가 있다고 임의로 "할랄 대체식 있음" 같은 정보를 추가 금지 (원문 우선). 단 사전 매핑/메타데이터에 있다면 그대로 전달
- [ ] **라마단·이드** 관련 한국 일정과의 충돌은 원문 우선. 보충 설명 임의 추가 금지
- [ ] **종교 표현 자제** — `إن شاء الله`, `بإذن الله` 등 자동 삽입 금지. 학교 통신문 톤은 행정·세속
- [ ] **그림·체육·수영** 등 종교·성별 민감 주제는 원문 그대로 번역. 임의 권고 추가 금지

### Meal / Allergy 표기
- [ ] `يحتوي على: حليب، بيض، قمح، فول الصويا` 형식
- [ ] critical 알레르겐/종교 제약 항목: 별도 줄로 강조 권장 — `⚠ يحتوي على لحم الخنزير` (사전 매핑 결과만)
- [ ] 사전 매핑 실패 시 절대 음역 추측 금지

### Naturalness 직역 안티 패턴
- `안녕하십니까` → ❌ `هل أنتم في سلام؟`, ✅ `حضرات أولياء الأمور الكرام،`
- `많은 협조 부탁드립니다` → ❌ `نطلب الكثير من التعاون`, ✅ `نشكركم على تعاونكم` 또는 생략
- `반드시 ... 해 주시기 바랍니다` → ❌ `يجب أن تفعلوا بالتأكيد`, ✅ `يُرجى التكرم بـ ...`
- `학교에서` → ❌ `من المدرسة` (모호), ✅ `في المدرسة`
- 명령형 직접 호명 (`أعطوا`, `أرسلوا`) → 정중형 `يُرجى إرسال ...` 로 변환

## 엔지니어가 아랍어 프롬프트 설계 시 다뤄야 할 항목

`prompts_ar.py`(분리 시) 또는 `translate_en_to_target_prompt`에서 `target_language == "ar"`일 때 다음 룰을 명시한다.

1. **MSA lock**: "Output in Modern Standard Arabic (الفصحى). Do not use dialect (Egyptian, Levantine, Gulf). Use formal administrative school register."
2. **Polite request structure**: "Use `يُرجى + masdar` or `نرجو من حضراتكم + masdar` for parent requests. Avoid bare imperatives addressed to parents."
3. **Numeric system**: "Use Western Arabic numerals (0–9), never Eastern (٠–٩). Keep consistent across the entire document."
4. **Date format**: "Use Gregorian dates only (`1 يونيو 2026 (الاثنين)`). Do NOT add Hijri dates unless explicitly in source."
5. **Religion neutrality**: "Do not insert religious expressions (`إن شاء الله`, `بسم الله`, `الحمد لله`) unless they exist in source. Keep the tone administrative and secular."
6. **Halal-sensitive ingredients**: "Pork, alcohol-derived ingredients, and gelatin require strict dictionary mapping. Never transliterate or guess. If unmapped, set `human_review_required=true`."
7. **BiDi and proper nouns**: "Korean school and personal names: render as MSA transliteration with the Korean form in parentheses if useful (`مدرسة "나란히"`). Preserve Korean phone numbers exactly with Western digits."
8. **Punctuation**: "Use Arabic punctuation `،` `؛` `؟` `…`. Do not leave Korean `·`, `~`, `「」` in output."
9. **Gender/number agreement**: "Apply correct verb-noun gender and number agreement, especially for numerals 3–10 (reverse gender) and 11–99 patterns."
10. **No invented context**: "Do not add cultural explanations, holiday context, or alternative menu suggestions that are not in source."

## 자주 보는 문제와 어디서 잡을 수 있는가

| 문제 | 발생 가능 단계 | 잡는 곳 |
|---|---|---|
| 동·서양 숫자 혼용 | 아랍어 단계 | 아랍어 전용 프롬프트의 numeric system 룰 |
| 헤지라력 임의 추가 | 영어 피벗에서 추가됨 | 영어 피벗 + 아랍어 단계 모두에서 "원문에 없으면 추가 금지" |
| 종교 관용어 자동 삽입 | 아랍어 단계 | 종교 중립 룰 강제 |
| 돼지/알코올 임의 음역 | 아랍어 단계 또는 사전 누락 | `map_ingredient_identity_prompt` 강화 + 아랍어 사전 보강 |
| 방언 표현 | 아랍어 단계 | MSA lock 룰 |
| BiDi 깨진 한국어/숫자 | 아랍어 단계 | RTL 처리 룰 + 따옴표/괄호 유지 명시 |
| 강압적 명령형 | 톤 룰 약함 | `يُرجى` 패턴 강제 |
