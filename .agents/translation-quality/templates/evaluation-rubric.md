# Evaluation Rubric

## North Star (모든 채점의 frame)

**번역 언어를 모국어로 사용하는 해외 이주민 학부모가 통신문을 정확하게 이해할 수 있어야 한다.**

평가자는 자신을 다음 페르소나에 둔다:
- 타겟 언어를 모국어로 함
- 한국 거주 이주민 학부모
- 한국 학교 문화 친숙도 낮음 (학예회·알림장·체험학습·돌봄교실·방과후 등 사전 지식 없다고 가정)
- 일반적 성인 가독 수준 (문학·법무·종교 고급 어휘 익숙하지 않음)

**8축 모두 위 페르소나 관점에서 채점한다.** 어떤 축이 5점이어도 "이주민 학부모가 무엇을/언제까지/어떻게 해야 할지 모름"이면 종합 verdict는 fail. 이 frame이 깨지는 모든 판단은 무효.

평가자 에이전트가 각 언어 번역을 채점할 때 사용하는 8축 × 0–5점 기준.

## 공통 점수 정의

| 점수 | 의미 |
|---|---|
| **5** | 완벽. 이 축에서 흠 잡을 곳 없음. 학교/기관 톤·정보·자연스러움 모두 만족. |
| **4** | 좋음. 사소한 어색함이 있지만 보호자 의사결정에 영향 없음. |
| **3** | 합격선. 의미는 전달되나 1–2건의 분명한 결함이 있음. |
| **2** | 위험. 보호자가 오해할 가능성이 명백히 있음. 자동수정으로는 부족. |
| **1** | 실패. 사실 왜곡, 누락, 또는 톤 붕괴로 사용 불가. |
| **0** | 미평가/해당 사항 없음 (예: 식재료 정보 없는 통신문의 Meal/Allergy 축). |

## 축별 세부 기준

### 1. Fact Preservation (사실 보존)

기계 검증 가능 사실: 날짜, 시간, 장소, 금액, 전화번호, 계좌번호, URL, 학년/반/대상, 인원수, 제출물, 마감.

- **5**: 모든 hard fact가 원문과 동일하게 보존. 코드 검증 PASS 그리고 사람이 봐도 일치.
- **4**: hard fact 모두 보존되지만 사소한 형식 차이(예: `2026-06-01` vs `1 June 2026`). 의미 동일.
- **3**: 1건의 비-critical 사실(예: 부수 설명)이 약간 어긋남.
- **2**: critical 사실 1건이 누락/변형 (날짜 단위, 금액 단위, 전화번호 자릿수 등).
- **1**: critical 사실 2건 이상 또는 단일 critical 사실이 보호자 행동을 잘못 유도.

### 2. Action Clarity (행동 명확성)

학부모/학생이 *무엇을 / 언제까지 / 어떻게* 해야 하는가.

- **5**: 모든 요구 행동이 명확. 마감과 절차가 한 번 읽고 잡힌다.
- **4**: 모든 행동이 분명하지만 한 번 다시 읽어야 함.
- **3**: 하나의 행동이 모호. 마감은 분명하나 방법이 흐릿하거나 그 반대.
- **2**: 핵심 행동 중 하나가 빠지거나 잘못 전달됨.
- **1**: 무엇을 해야 하는지 보호자가 결정 불가.

### 3. Tone & Register (톤과 격식)

한국어 학교 공식 통신문 톤(공손·공식·중립)을 타겟 언어의 적절한 격식으로 매핑했는가. **단 north star 우선** — 이주민 학부모가 부담 없이 읽을 수 있는 격식이어야 한다. 너무 고급한 격식(고전적 MSA, 문학적 러시아어, 법무체 영어)은 학교 공식 톤일지라도 이 페르소나에는 장벽이므로 감점 사유.

- **5**: 공식·정중하면서도 이주민 학부모가 한 번에 이해. 학교 공공 행정 등록.
- **4**: 톤은 적절하나 1–2 문장이 약간 캐주얼하거나 약간 격식 과잉.
- **3**: 격식이 한 단계 어긋남 (비즈니스 톤 / 너무 문학적 / 너무 캐주얼).
- **2**: 강압적·명령형이 두드러지거나 친구 메시지처럼 보임. 또는 격식 과잉으로 이해 장벽.
- **1**: 보호자가 모욕감/불편함을 느끼거나 격식이 너무 높아 이해 불가.

### 4. Completeness (완전성)

원문 정보 누락 없음, 원문에 없는 정보 추가 없음.

- **5**: 1:1 정보 대응.
- **4**: 사소한 부수 설명 한 줄 정도 누락 또는 추가 (의미 영향 없음).
- **3**: 의미 영향 없는 누락/추가 2–3건.
- **2**: 보호자 의사결정에 영향 있는 누락 또는 원문에 없는 사실 추가 1건.
- **1**: 다수 누락/추가로 다른 통신문처럼 보임.

### 5. Naturalness / Readability (자연스러움 / 이해도)

이주민 학부모가 한 번에 이해하는가. 직역체/기계어투 점검. **이해도가 자연스러움보다 우선** — 매끄럽지만 이해 어려운 고급 문체는 매끄럽지 않지만 명확한 문장보다 낮은 점수다.

- **5**: 모국어로 자란 이주민 학부모가 한 번에 이해. 명확하고 자연스러움.
- **4**: 사소한 어색함이 1–2건 있지만 이해에 지장 없음.
- **3**: 직역 흔적이 보이거나 한 번 더 읽어야 하는 문장이 있다.
- **2**: 기계 번역 티가 명백하거나, 고급 문체로 이해 장벽 발생.
- **1**: 어순/연결/어휘 난도로 의미를 잡기 어려움.

### 6. Cultural & Linguistic Appropriateness (문화·언어 적절성)

호칭, 존대 매핑, 숫자/날짜 표기, 종교·문화적 함의. **한국 학교 특유 개념은 보호자가 처음 본다고 가정** — 학예회·알림장·돌봄교실·방과후·체험학습 등은 이주민 학부모가 잘 모를 수 있다. 단순 음역이나 한국어 잔존은 감점, 의미·목적이 풀려 있으면 가점 (단 hard fact는 보존). 언어별 세부 항목은 `language-criteria/<lang>.md` 필수 참조.

- **5**: 타겟 문화/언어 규범에 부합 + 한국 학교 개념이 이주민 학부모에게 이해 가능하게 처리됨.
- **4**: 사소한 표기 관습 위반 (예: 영국식/미국식 혼용) 또는 학교 개념 처리가 약간 모호.
- **3**: 1건의 명확한 문화·언어적 어색함 또는 학교 특유 개념이 풀리지 않아 이해 모호.
- **2**: 보호자에게 무례·혼란 / 학교 특유 개념이 단순 음역만 되어 의미 전달 실패.
- **1**: 문화적/종교적으로 부적절 (예: 아랍어 통신문에서 종교적 함의 식재료를 임의 매핑).

### 7. Meal / Allergy Accuracy (식재료/알레르기 정확성)

승인 사전 매핑 사용 여부, 임의 번역 흔적, critical 알레르겐/종교 제약 항목 표기.

- **0**: 식재료 정보 없음 (해당 없음).
- **5**: 모든 식재료가 사전 매핑됨. critical 항목은 강조 또는 별도 표기.
- **4**: 사전 매핑이지만 표기 형식이 약간 흔들림.
- **3**: 비-critical 식재료 1건이 미매핑이지만 human_review_required로 표시됨.
- **2**: critical 식재료(돼지/소/닭/해산물/견과/우유/계란/밀/콩/알코올 유래/젤라틴 등)가 임의 번역됨.
- **1**: critical 식재료 누락 또는 잘못 매핑되어 안전 위험.

### 8. Safety & Risk (안전·위험)

오역이 학생 안전/건강/출결/납부/참여에 영향 줄 가능성. 0/3/5만 사용.

- **5**: 안전 위험 없음.
- **3**: 잠재적 혼란은 있으나 안전 영향 가능성 낮음.
- **0**: 안전/건강/출결/납부에 직접 영향 줄 오역 존재. critical 이슈로 분류 필수.

이 축은 다른 축의 합산에 큰 가중치(×2 권장).

## 가중 평균 계산

```
weighted_avg(lang) =
  ( fact*1.0 + action*1.0 + tone*0.8 + completeness*0.8
  + natural*0.7 + culture*0.8 + meal*0.7 + safety*2.0 ) / 8.8
```

`scores.json` 예시:

```json
{
  "en": {
    "fact": 4.0,
    "action": 4.5,
    "tone": 3.0,
    "completeness": 4.0,
    "naturalness": 3.5,
    "culture": 4.0,
    "meal": 0,
    "safety": 5.0,
    "weighted_avg": 4.05,
    "critical_count": 0
  },
  "ru": {...},
  "ar": {...}
}
```

## Stopping Criteria — 언제 멈추는가

이 시스템은 끝없이 돌지 않는다. 충분한 품질에 도달하면 즉시 멈춘다. 평가자는 매 이터레이션 끝에 다음 4가지 verdict 중 하나를 선택한다.

### `ship_ready` — 하드 스톱 (자동 종료)

다음을 **전부** 만족하면 더 이상 이터레이션 하지 않는다.

- 세 언어 모두 `train_avg_overall ≥ 4.2` AND `held_out_avg_overall ≥ 4.0`
- 세 언어 모두 `critical_count == 0`
- 세 언어 모두 `safety axis ≥ 4`
- 세 언어 모두 `fact ≥ 4` AND `action ≥ 4` AND `meal ≥ 4` (meal=0인 통신문은 평균에서 제외)
- **Comprehension Pass 전체 통과** — 모든 training+held-out 통신문에서 "무엇/언제/어떻게" 3질문에 답 가능 (north star 기준)
- 직전 2회 이터레이션 모두에서 held-out avg 하락 없음

### `diminishing_returns` — 소프트 스톱 (사용자 확인 후 종료)

다음 중 하나 충족 시. team-lead는 사용자에게 옵션 제시 후 결정:

- 2 연속 이터레이션에서 held-out avg 개선 폭 < 0.1 AND 남은 이슈가 critical 0건, high 0~1건
- 엔지니어가 `improvement-plan.md`에 "no high-leverage change available" 표시
- 평가자가 같은 이슈를 3회 연속 동일하게 지적했으나 매번 small fix만 적용되어 진척 미약

사용자 옵션:
- 그대로 종료 (ship_ready 기준에 못 미쳐도 OK라고 판단)
- 새 통신문(다양성 매트릭스 보완) 추가 후 1~2회 더
- 특정 언어만 추가 개선 (다른 언어는 lock-in)

### `blocking_regression` — 강제 정지 (사용자 결정 대기)

- 3 연속 이터레이션 held-out 회귀 (`generalization_gap` 0.3 이상 확대)
- 또는 직전 이터에서 한 언어가 0.5점 이상 급락
- → 과적합 의심. 자동 다음 이터 금지. rollback / 룰 일반화 / 평가 기준 변경 등 사용자 결정 필요

### `needs_iteration` — 일반 진행

위 셋 중 어디에도 해당 없음. 의미 있는 개선 여지가 남아 있고 회귀도 없음. 다음 이터로 자동 진행.

## 종료 판정 책임

- **평가자**: `feedback-report.md` 최상단 `Verdict:` 필드에 4가지 중 하나 명시 + 판단 근거 한 줄
- **team-lead (코디네이터)**: `ship_ready` / `diminishing_returns` / `blocking_regression` 셋 중 하나면 **자동 다음 이터 시작하지 않고** 사용자에게 보고. `needs_iteration`일 때만 자동 진행.
