# 나란히 앱 디자인 리뉴얼 계획서

작성일: 2026-06-02

## 1. 목표

`로고및캐릭터디자인` 폴더의 로고와 캐릭터 이미지를 기준으로, 현재 흑백 중심의 기능형 앱 UI를 더 따뜻하고 친근한 학교 생활 도우미 경험으로 리뉴얼한다.

핵심 방향은 다음과 같다.

- 학부모와 아이가 함께 쓰기 편한 부드러운 분위기
- 공지, 급식, 일정 같은 실용 정보는 읽기 쉽게 유지
- 캐릭터는 장식이 아니라 상태 안내, 빈 화면, 완료 피드백, 온보딩의 안내자 역할로 사용
- 기존 Next.js/Tailwind 토큰 구조를 유지하면서 점진적으로 적용

## 2. 현재 앱 디자인 진단

현재 앱은 `app/globals.css`의 토큰을 중심으로 흑백, 흰 배경, 회색 카드, 간단한 카테고리 컬러를 사용한다.

장점:

- 정보 밀도가 높고 모바일에서 읽기 쉽다.
- 공지 카드의 카테고리 구분이 명확하다.
- 다국어/RTL 구조를 이미 고려하고 있다.
- `max-w-app: 480px` 모바일 앱형 레이아웃이 안정적이다.

개선 필요:

- 브랜드 첫인상이 약하다. 현재 앱명과 아이콘만으로는 캐릭터 정체성이 드러나지 않는다.
- 홈/온보딩/빈 상태가 다소 건조하다.
- 버튼과 카드가 기능적으로는 명확하지만, 캐릭터 이미지의 말랑한 3D 톤과 시각적으로 맞지 않는다.
- PWA 아이콘은 현재 로고 자산과 일관되게 업데이트할 여지가 있다.

## 3. 참고 자산 분석

자산 위치: `로고및캐릭터디자인/`

대표 자산:

| 자산 | 권장 사용처 |
|---|---|
| `로고.png` | 앱 아이콘, 로그인/스플래시, 설정 상단 브랜드 영역 |
| `나리누리같이손흔들기.png` | 온보딩 첫 화면, 로그인 환영 화면 |
| `나리누리같이종이읽기.png` | 공지/번역 안내, 공지 빈 상태 |
| `나리누리서서종이같이.png` | 공지 처리 중, 번역 완료 안내 |
| `나리누리손잡고서있기.png` | 가족/학교 연결 메시지, 설정 프로필 영역 |
| `나리포인트.png`, `누리포인트.png` | 도움말, 강조 안내, 툴팁성 빈 상태 |
| `나리따봉.png`, `누리따봉.png` | 저장 완료, 처리 성공, 긍정 피드백 |
| `나리앉아서책읽기.png`, `누리서서책읽기.png` | 급식/일정 없음, 읽기/대기 상태 |
| `나리걷기.png`, `누리걷기.png`, `나리누리같이걷기.png` | 로딩, 이동, 다음 단계 진행 |

시각 특징:

- 파스텔 블루와 옐로가 주인공인 밝은 3D 캐릭터
- 코랄 핑크 볼, 오렌지 부리/발, 브라운 눈매가 보조 포인트
- 둥근 형태, 부드러운 하이라이트, 흰 배경과 잘 맞는 그림자
- 앱 UI도 날카로운 미니멀보다 부드러운 카드, 밝은 배경, 낮은 대비의 보조면이 어울림

## 4. 새 디자인 컨셉

컨셉명: `함께 챙기는 학교 생활`

디자인 원칙:

- 캐릭터는 화면을 가리지 않는 작은 안내자로 사용한다.
- 정보 화면은 기존처럼 조용하고 스캔 가능해야 한다.
- 중요한 액션은 브랜드 블루, 긍정/완료는 옐로, 주의는 기존 경고색을 사용한다.
- 배경은 완전한 흰색보다 아주 옅은 블루/아이보리 톤을 섞어 캐릭터와 연결한다.
- 둥근 요소를 늘리되, 반복 카드의 반경은 과하게 키우지 않는다.

## 5. 컬러 토큰 제안

현재 `primary: #111111` 중심에서 캐릭터 기반 브랜드 팔레트로 확장한다.

| 용도 | 토큰명 제안 | 색상 제안 | 설명 |
|---|---|---:|---|
| 브랜드 메인 | `--color-primary` | `#5DAFEA` | 누리의 파스텔 블루 기반 |
| 브랜드 활성 | `--color-primary-active` | `#3F94D4` | 버튼 active/selected |
| 브랜드 소프트 | `--color-primary-soft` | `#EAF7FF` | 헤더/정보 박스 배경 |
| 브랜드 세컨더리 | `--color-brand-sun` | `#FFD75A` | 나리의 옐로 포인트 |
| 세컨더리 소프트 | `--color-brand-sun-soft` | `#FFF7D6` | 완료/빈 상태 배경 |
| 코랄 포인트 | `--color-brand-coral` | `#FF9CA3` | 볼터치/알림 보조 포인트 |
| 오렌지 포인트 | `--color-brand-orange` | `#FF9A22` | 캐릭터 부리/발, 강조 아이콘 |
| 잉크 | `--color-ink` | `#2B211C` | 검정보다 부드러운 브라운 블랙 |
| 배경 | `--color-canvas` | `#FBFDFF` | 앱 전체 배경 |
| 카드 | `--color-surface-card` | `#FFFFFF` | 정보 카드 |
| 카드 보조 | `--color-surface-soft` | `#F3FAFF` | 섹션/빈 상태 |

기존 카테고리 색은 유지하되 톤을 살짝 부드럽게 조정한다.

- 준비물: 그린 유지, 배경을 더 옅게
- 해야 할 일: 오렌지 계열 유지
- 일정: 브랜드 블루와 통합

## 6. 타이포그래피

현재 Noto 계열 다국어 폰트 스택은 유지한다.

조정 제안:

- 화면 제목: `text-xl` 또는 `text-2xl`, `font-bold`
- 카드 제목: `text-base`, `font-semibold`, 줄간격 `leading-snug`
- 보조 설명: `text-sm`, `text-muted`
- 하단 내비게이션: `11px` 유지하되 활성 상태에 브랜드 블루 적용
- 한글 본문은 자간 0 유지

## 7. 레이아웃 원칙

- 모바일 앱형 `max-w-app: 480px` 구조 유지
- 상단 헤더는 흰색 고정 헤더에서 옅은 블루 배경의 브랜드 헤더로 전환
- 홈 첫 영역에는 작은 캐릭터와 아이/학교 정보를 함께 배치
- 카드 안에 또 다른 카드가 들어가지 않도록 반복 리스트는 단일 카드만 사용
- 이미지가 텍스트를 덮지 않도록 캐릭터 영역은 고정 높이 또는 `aspect-ratio` 지정
- 하단 탭은 기존 4개 구조 유지, 활성 아이콘과 텍스트는 브랜드 블루 사용

## 8. 화면별 리뉴얼 계획

### 로그인

목표: 앱의 첫인상에서 캐릭터와 브랜드를 확실히 보여준다.

변경안:

- 상단에 `로고.png` 또는 `나리누리같이손흔들기.png` 사용
- 배경은 `primary-soft` 계열의 밝은 블루
- 로그인 버튼은 기존 소셜 버튼 구조 유지, 메인 액션은 브랜드 블루
- 문구는 짧게: “학교 공지를 내 언어로, 나란히”

### 온보딩

목표: 학교/아이 정보 입력 과정을 덜 딱딱하게 만든다.

변경안:

- 1단계 학교 검색: `나리포인트.png` 또는 `누리포인트.png`
- 2단계 아이 정보: `나리누리손잡고서있기.png`
- 진행 점은 검정 대신 브랜드 블루/옐로 조합
- 고정 하단 버튼은 브랜드 블루, disabled는 낮은 투명도

### 홈/공지 목록

목표: 가장 중요한 정보 화면이므로 캐릭터는 작게, 정보는 크게.

변경안:

- 상단 홈 헤더를 “오늘 챙길 학교 소식” 형태의 브랜드 헤더로 전환
- 헤더 오른쪽에 작은 `나리누리같이종이읽기.png`
- 공지 카드 배경은 흰색, 얕은 그림자, 왼쪽 카테고리 바 유지
- 공지 처리 중에는 `나리누리서서종이같이.png`를 작은 상태 일러스트로 사용
- 공지 없음 상태에는 `누리서서책읽기.png`와 간단한 안내 문구 사용

### 공지 상세

목표: 번역된 카드 내용을 읽기 쉽게 유지한다.

변경안:

- 상세 상단에 카테고리별 소프트 배경 밴드 추가
- 번역 처리/오류/완료 상태별 캐릭터 사용
- 요약, 준비물, 해야 할 일, 일정 카드의 색상은 기존 의미 체계 유지
- 중요한 날짜/제출물은 브랜드 오렌지 또는 카테고리 색으로 강조

### 급식

목표: 일주일 급식 정보를 밝고 가볍게 보여준다.

변경안:

- 주간 헤더에 `나리앉아서책읽기.png` 또는 `나리따봉.png`를 작게 배치
- 급식 없음 상태에는 `누리서서책읽기.png`
- 알레르기 표시는 캐릭터 톤과 별개로 명확한 경고색 유지
- 날짜 탭/주 이동 버튼은 브랜드 블루 outline 스타일

### 캘린더/수업

목표: 일정과 시간표의 구조적 가독성을 우선한다.

변경안:

- 월간 일정 탭은 기존 밀도를 유지
- 선택된 날짜/오늘 표시를 브랜드 블루로 통일
- 일정 없음 상태는 `나리누리같이걷기.png` 또는 `나리포인트.png`
- 수업 없음/지원 안 됨 상태는 `누리포인트.png`와 간단한 안내

### 설정

목표: 계정/학교 정보 화면에 브랜드 신뢰감을 더한다.

변경안:

- 상단 프로필 영역에 `나리누리손잡고서있기.png`
- 학교 재선택, 언어 변경, 로그아웃은 섹션형 리스트로 정리
- 위험 액션은 브랜드 색이 아니라 기존 error 색 유지

## 9. 컴포넌트 변경 계획

우선 정의할 공통 컴포넌트:

| 컴포넌트 | 목적 |
|---|---|
| `BrandHeader` | 홈/급식/캘린더/설정 상단 브랜드 헤더 |
| `CharacterEmptyState` | 공지 없음, 급식 없음, 일정 없음 상태 |
| `CharacterStatusBanner` | 처리 중, 완료, 오류 안내 |
| `PrimaryButton` | 온보딩/저장/로그인 액션 일관화 |
| `SoftPanel` | 캐릭터가 포함된 안내 영역 |

컴포넌트 상태:

- 버튼: default, active, disabled, loading
- 상태 배너: info, success, warning, error
- 빈 상태: compact, full
- 캐릭터 이미지: small 64px, medium 120px, hero 220px

접근성:

- 캐릭터 이미지는 정보 전달이 없으면 `alt=""`
- 상태 안내 이미지는 `alt`보다 주변 텍스트로 의미 전달
- 버튼은 최소 44px 터치 영역 유지
- 색상만으로 상태를 구분하지 않고 텍스트 라벨 유지

## 10. 자산 적용 방식

현재 이미지는 앱 public 경로 밖에 있으므로, 실제 구현 시 다음 경로로 복사해 사용한다.

```text
public/characters/
  logo.png
  nari-point.png
  nuri-point.png
  nari-nuri-wave.png
  nari-nuri-reading-paper.png
  nari-nuri-standing-paper.png
  nari-nuri-holding-hands.png
  nari-thumb.png
  nuri-thumb.png
```

권장 방식:

- 파일명은 영문 kebab-case로 정리
- 원본은 `로고및캐릭터디자인/`에 보존
- Next.js `Image` 컴포넌트로 렌더링
- 화면별 이미지 크기를 고정해 레이아웃 흔들림 방지
- PWA 아이콘은 `로고.png` 기반으로 `public/icons` 재생성

## 11. 구현 우선순위

### 1단계: 브랜드 토큰과 자산 정리

- `public/characters` 생성 및 대표 이미지 복사
- `app/globals.css` 컬러 토큰 업데이트
- PWA `themeColor`를 브랜드 블루 계열로 변경
- 기존 흑백 버튼이 깨지지 않도록 호환 토큰 유지

### 2단계: 온보딩/로그인 리뉴얼

- 첫인상 화면에 캐릭터 적용
- 주요 버튼과 진행 표시를 브랜드 톤으로 변경
- 모바일 화면에서 이미지와 입력 폼 겹침 여부 확인

### 3단계: 홈/공지 카드 리뉴얼

- 홈 헤더에 캐릭터 적용
- 공지 카드의 흰색 카드, 소프트 배경, 카테고리 바 조정
- 공지 없음/처리 중 상태에 캐릭터 상태 컴포넌트 적용

### 4단계: 급식/캘린더/설정 확장

- 공통 헤더와 빈 상태 컴포넌트 재사용
- 일정/급식 화면은 정보 밀도를 유지하면서 캐릭터는 보조적으로만 사용

### 5단계: 최종 QA

- 모바일 375px, 390px, 430px, 데스크톱 480px 이상 확인
- 한국어/영어/긴 다국어 문구 줄바꿈 확인
- RTL 언어에서 이미지/아이콘 배치 확인
- PWA 아이콘, manifest, themeColor 확인

## 12. QA 체크리스트

- [ ] 모든 캐릭터 이미지가 `public` 경로에서 정상 로드된다.
- [ ] 홈 첫 화면에서 브랜드와 핵심 정보가 동시에 보인다.
- [ ] 캐릭터 이미지가 버튼, 입력창, 카드 텍스트를 가리지 않는다.
- [ ] 공지 카드의 카테고리 구분이 기존보다 약해지지 않는다.
- [ ] 비어 있는 상태, 로딩 상태, 오류 상태가 각각 다르게 보인다.
- [ ] 버튼 disabled/loading 상태가 명확하다.
- [ ] 색 대비가 주요 텍스트 기준으로 충분하다.
- [ ] 하단 내비게이션 활성 상태가 명확하다.
- [ ] 다국어 긴 문구가 카드와 버튼 밖으로 넘치지 않는다.

## 13. 최종 디자인 방향 요약

나란히의 새 앱 디자인은 “캐릭터가 있는 귀여운 앱”이 아니라, “학교 생활 정보를 따뜻하게 챙겨주는 실용 앱”이어야 한다. 캐릭터는 온보딩, 빈 상태, 상태 안내에서 브랜드 감정을 만들고, 공지/급식/일정 화면에서는 기존의 빠른 정보 확인 경험을 유지한다.

가장 먼저 적용할 화면은 온보딩과 홈이다. 두 화면에서 캐릭터와 브랜드 팔레트가 자연스럽게 자리 잡으면, 공지 상세와 급식/캘린더는 같은 컴포넌트를 재사용해 안정적으로 확장할 수 있다.
